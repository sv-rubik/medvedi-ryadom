# Медведи рядом

Карта опубликованных сообщений о выходах медведей к людям и нападениях. Тёмная тема; административные границы скрываются на уровне стиля карты. Указанные координаты могут обозначать центр населённого пункта, если место события неизвестно.

Данные находятся в `dist/events.json`. Фильтр содержит годы с 1991-го по текущий, но архив за эти годы пока не заполнен полностью. Изменения `events.json` публикуются после отправки в ветку `main`.

## GitHub Pages

В настройках репозитория выберите **Settings → Pages → Build and deployment → Source: GitHub Actions**. Файл `.github/workflows/pages.yml` публикует папку `dist` по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`. Репозиторий должен быть публичным для GitHub Free. Содержимое сайта будет открыто всем после публикации.

## Карта

MapLibre GL JS 5.12.0 хранится в `dist/vendor` вместе с лицензией, поэтому карта не зависит от загрузки JavaScript с CDN. Картографическая подложка поступает из OpenFreeMap и должна быть доступна устройству посетителя. При недоступности подложки сообщения остаются в списке.

## Обновления

Данные редактируются в `dist/events.json`. После отправки изменений в ветку `main` GitHub Actions повторно публикует сайт. Не публикуйте событие без даты происшествия, места и доступного источника; повторные сообщения об одном событии объединяйте.
