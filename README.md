# Медведи рядом

Карта сообщений о встречах с медведями и нападениях, отдельная лента других новостей и исторический поисковый архив. Публичная версия: https://sv-rubik.github.io/medvedi-ryadom/

## Данные

- `dist/events.json` — точки карты. `eventDate` у проверенных записей означает дату происшествия. У автоматически найденных записей `dateBasis: publication` означает, что известна только дата публикации. Для периодов и неполных дат используются `range`, `month` и `year`. Точка может обозначать центр региона или населённого пункта, а не положение зверя.
- `dist/news.json` — другие новости о медведях, например о регулировании численности.
- `dist/history.json` — заголовки, найденные в новостном индексе. Если место удалось определить, запись ссылается на точку карты через `mappedEventId`; остальные остаются только в архиве.
- `data/curated-2016-2026.md` — переданный владельцем список из 79 строк. Для 77 строк указано место, две строки содержат общие показатели без одного места. Часть ссылок и деталей списка требует отдельной проверки.
- `data/news-archive.csv` — сохранённые версии записей, включая правки. После исчезновения исходной страницы заголовок, дата, источник, ссылка и сохранённое описание остаются здесь.
- `dist/population.json` — ряд численности бурого медведя за 2019–2024 годы из публикаций Росстата. Показатели не монотонны.

## Ежедневный поиск

GitHub Actions запускает `.github/workflows/pages.yml` в 20:50 UTC (23:50 МСК) и по запросу из вкладки Actions. `scripts/update_news.py` ищет только публикации **текущего календарного дня по Москве** в поисковой RSS-ленте Bing News, включая выборки по РИА Новости, ТАСС, РБК, Интерфаксу, «Коммерсанту», «Ленте.ру» и «Российской газете». Скрипт пытается прочитать текст первоисточника, сохраняет ссылку на него и ищет географическое название. Если место удаётся определить, публикация получает приблизительную точку и явный статус «не проверено». Точка никогда не означает положение медведя сейчас.

`scripts/collect_history.py` в том же ежедневном запуске проверяет только текущий день в индексе Google Новости, в том числе публикации Дзена. `scripts/promote_history.py` добавляет на карту заголовки отдельных происшествий, для которых удалось определить место в России; дата публикации и приблизительная точность помечаются явно. Остальные публикации сохраняются только в архиве. Исторический поиск запускается **один раз** командой `python scripts/collect_history.py --all`; он не включён в расписание.

Первоначальный перенос пользовательского списка выполняется `scripts/import_curated.py`; `scripts/split_grouped_cases.py` ставит отдельные точки для шести явно различимых случаев внутри сгруппированных строк, а `scripts/curate_recent.py` и `scripts/audit_curated_sources.py` сверяют место, повторы и ссылки. Если в присланном списке нет рабочего адреса публикации и её не удалось однозначно найти, карточка прямо помечает ссылку как поиск источника. Общие показатели СМИ, например 17 погибших с начала 2026 года и 166 нападений в 2014 году, приведены в разделе «О карте», но не подменяют собой отдельные происшествия.

После сбора `scripts/export_archive.py` добавляет новые версии записей в CSV. Затем workflow сохраняет изменения в `main` и публикует папку `dist` на GitHub Pages. Записи из поисковых индексов не заменяют редакционную проверку и не гарантируют полноту всех происшествий.

## Редактирование

Страница `admin.html` позволяет владельцу добавить, исправить или удалить точки, новости и записи поискового архива. Для записи нужен [fine-grained GitHub token](https://github.com/settings/personal-access-tokens/new), ограниченный репозиторием `sv-rubik/medvedi-ryadom`, с правом **Contents: Read and write**. Токен вводится в браузере и не сохраняется в файлах сайта или локальном хранилище. Из исторического архива можно создать черновик точки, затем дополнить текст, дату и координаты. Удалённые автоматические записи добавляются в `ignoredUrls`, чтобы следующий сбор не вернул их на сайт.

## Карта и источники

MapLibre GL JS 5.12.0 лежит в `dist/vendor` с лицензией. Подложка поступает из OpenFreeMap. Координаты автоматически ищутся через публичный Nominatim с кешированием и ограничением до одного запроса в секунду; [правила сервиса](https://operations.osmfoundation.org/policies/nominatim/) соблюдаются. При недоступности подложки карточки остаются в списке.

График использует данные Росстата: [2019–2023](https://rosstat.gov.ru/storage/mediabank/Oxrana_okruj_sredi_2024.pdf), [2024](https://rosstat.gov.ru/storage/mediabank/Rossia_2025.pdf).
